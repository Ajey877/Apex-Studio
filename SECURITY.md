# Security Policy

## Supported versions

Security fixes are developed against the current `main` branch and the latest published release.

## Reporting a vulnerability

Please do not publish security vulnerabilities in a public GitHub issue.

Use GitHub's private vulnerability reporting/security advisory mechanism for this repository when available. Include:

- A clear description of the vulnerability.
- Reproduction steps or a proof of concept.
- The affected version or commit.
- Any relevant logs or screenshots that do not contain secrets or personal data.

Please allow reasonable time for investigation and remediation before public disclosure.
