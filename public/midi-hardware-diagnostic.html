External MIDI Hardware Diagnostic

A standalone bench tool for raw Web MIDI I/O checks. It does not call Apex Studio’s real-time playback engine or modify a project.

Hardware test only. This page sends MIDI to the selected output. Start with your synth volume low, select the intended device/channel, and connect a MIDI loopback input only when you want byte-by-byte return capture. This test page cannot prove sound generation without an actual synth.

Permission and device identity

Permission: Not requested Selected output: None Secure context: Checking

Web MIDI requires a supported browser and a secure context (HTTPS or localhost). Browser permission is requested only after you click below. Device IDs are recorded locally in the downloaded test log.

Selected physical route

Use a MIDI interface output patched to its input (or another explicitly selected loopback path) to verify the bytes actually return through the interface. A JavaScript fake port is not hardware evidence.

Controlled message tests

Panic is intentionally limited to the selected output and MIDI channel, but CC123 affects every voice on that synth channel. Reconnect recovery below does not send CC123; it releases only tracked pitches and sustain state.

Loopback comparison

Exact-byte counts identify missing, duplicate, or channel-misrouted loopback messages. Timestamp deltas are measurements from this interface path, not a preset acceptance threshold.
