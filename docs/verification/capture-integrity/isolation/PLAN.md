# Post-readiness frame isolation

Reuses captureWithReadiness and the unchanged analyzeReady contract. Every case
uses a fresh context/node/port/store and UUID. Existing 42+15 local raw files and
hosted archives are preserved. No product imports, FX, exports or production edits.

Modes (32 quanta and exact PCM tolerances unchanged):
- lead: existing scheduling lead 250 ms, 100 ms pre-source silence, 150 ms tail.
- no-ready: same lead/source/window, but scheduling does NOT wait for ready delivery.
  The processor still emits and proves readiness; arm may precede it in this
  explicitly identified control. Original contract result is retained separately.
- immediate: source scheduled at the current sample frame upon ready receipt,
  with zero pre-source lead. No late samples are excused: direct PCM and coverage
  comparisons still fail. Original scheduling contract can intentionally fail.
- generated: no BufferSource connection/start. A continuous deterministic,
  frame-addressed nonperiodic signal is generated by the worklet and captured
  from its output. Exact generated samples are independently checked. Input
  layout remains reported; this is not claimed to be BufferSource PCM fidelity.

Orthogonal integrity checks are the same for every control: all callback records
remain in receiver order, 32-quanta readiness must be provable, no post-ready
clock discontinuity or source-window hole/duplicate/conflict is excused. The
original baseline contract is still reported; no control pass replaces it.

Instrumented fields include callback-local count and instance ID, frame on entry,
after copy and before posting, currentTime, preceding transferred-buffer detached
length, all channel lengths, and checksum/PCM. Main-thread traces cover context,
ready receipt, arm send/receipt, source.start call/return, end receipt, drain,
disconnection, context close and port close. Raw records retain ALL events; first
anomaly summaries include neighboring callbacks and lifecycle traces.

Hosted matrix: both browsers x four modes; ten repetitions each of short (1 s),
long (10 s), workload (3 s, 12 ms busy every 20 ms). Single worker, no retries.
Any failing experiment retains failure job status after uploading evidence.
Python reanalysis is independent of the TS classifier. Raw bytes are artifacts,
not Git data. Hash-verified gzip/base64 annotations avoid prior size/count limits.

First local instrumentation prototype shadowed the trace function with the
MessageEvent parameter and timed out before scheduling. That raw run remains in
ignored readiness/results/isolation; it is not counted as a verified trial. The
trace helper was renamed, lint passed, and all four short smoke modes passed.
Synthetic tests check classification, not live reproduction or browser cause.
